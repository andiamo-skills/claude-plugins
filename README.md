# Claude plugins

Two small Claude plugins, each made of one skill:

- [termkeeper](termkeeper) — explains material written in another language (usually English) in your own language, while keeping technical and key terms in the material's language. Live in Anthropic's Claude plugin directory.
- [chat-baton](chat-baton) — writes a handoff file so you can continue a long chat in a fresh one.

Each folder is a separate plugin with its own README and MIT license.
