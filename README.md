# Claude plugins

Two small Claude plugins, each made of one skill:

- [termkeeper](termkeeper) — explains any material in another language (usually English: slides, documents, contracts, reports, articles) in your own language, while keeping technical and key terms in the material's language. Live in Anthropic's Claude plugin directory.
- [chat-baton](chat-baton) — writes a handoff file so you can continue a long chat in a fresh one.

Each folder is a separate plugin with its own README and MIT license.

## Install in Claude Code
This repository is also a plugin marketplace:
```
/plugin marketplace add andiamo-skills/claude-plugins
/plugin install termkeeper@andiamo-skills
```
